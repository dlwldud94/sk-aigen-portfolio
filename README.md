# SK AI GÉN 포트폴리오 웹사이트

## 실행
`index.html`을 브라우저에서 열면 됩니다. 별도의 빌드나 설치가 필요 없는 정적 웹사이트입니다. 인터넷이 연결되면 Google Fonts를 사용하며, 오프라인에서는 시스템 폰트로 대체됩니다.

## 실제 자료 교체
`assets/` 폴더에 아래 파일명을 정확히 맞춰 넣으면 새로고침할 때 자동으로 표시됩니다.

- `service-screen.jpg`: 공개 가능한 북팔 서비스 화면
- `presentation.jpg`: 대학원 AI 추천 시스템 발표 슬라이드 캡처
- `art-01.jpg`: 직접 그린 작품 1
- `art-02.jpg`: 직접 그린 작품 2

이미지 파일이 없으면 디자인된 플레이스홀더가 나타납니다. PNG 등을 쓰려면 HTML `data-image`, JS `assetMap` 및 `data-art` 값을 함께 바꾸세요.

## 수정 위치
- `index.html`: 문구와 섹션 내용
- `styles.css`: 색상, 레이아웃, 애니메이션, 모바일 반응형 스타일
- `script.js`: 스크롤 표시, 메뉴, 이미지 자동 로딩, 작품 확대 기능

## 배포
GitHub Pages, Netlify, Vercel 등의 정적 사이트 호스팅에 폴더 내용을 올리면 됩니다. 별도 백엔드가 필요하지 않습니다.
